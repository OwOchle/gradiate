# Gradiate
![Gradiate Text](https://github.com/OwOchle/gradiate/blob/main/assets/gradiate.png?raw=true)

Just a quick CLI to create beautiful gradients in your terminal

# Usage
```
Generate gradients in your terminal

Usage: gradiate [OPTIONS] [TEXT]...

Arguments:
  [TEXT]...  The text to color, empty for stdin

Options:
  -c, --colors <COLORS>            Colors of the gradient separated by commas (,)
  -o, --line-offset <LINE_OFFSET>  Gradient offset between lines [default: 0.1]
  -s, --space <SPACE>              Color space used for color mixing [default: hsv] [possible values: rgb, hsv]
  -h, --help                       Print help (see more with '--help')
  -V, --version                    Print version
```
